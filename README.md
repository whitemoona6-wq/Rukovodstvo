2. Запуск приложения

Установите Python 3 и Flask (если ещё не установлены):Bashpip install -r requirements.txt

Откройте в браузере: http://127.0.0.1:5000

Приложение можно также открыть напрямую через файл index.html (функциональность будет такой же, данные сохраняются в localStorage браузера).

5. Разделы системы
5.1. Сводка

Карточки с ключевой статистикой (количество единиц техники, суммарная стоимость, количество в ремонте и т.д.).
Диаграммы распределения по типам техники и по статусам.
Кнопка «Обновить» пересчитывает показатели.

5.2. Техника (Реестр техники)
Основной раздел учёта оборудования.
Поля записи:

Инвентарный номер (уникальный)
Наименование
Модель
Серийный номер
Тип (ПК, Ноутбук, Сервер, Периферия, Проектор, Интерактивная доска, Сетевое оборудование, Другое)
Кабинет / место расположения
Ответственный (из справочника)
Дата приобретения
Стоимость
Статус: В эксплуатации, В ремонте, На складе, Списано
Дата последнего ТО
Примечание

Возможности:

Поиск по любому полю
Фильтры по типу, статусу и кабинету
Добавление, редактирование и удаление (только администратор)
Рекомендация: технику не удалять, а переводить в статус «Списано»

5.3. Ответственные
Справочник материально ответственных лиц.
Поля: ФИО, должность, кабинет, телефон, e-mail.
Администратор может добавлять, редактировать и удалять записи. При добавлении/редактировании техники список ответственных подставляется из этого справочника.
5.4. Обслуживание
Журнал технического обслуживания и ремонтов.
Поля записи:

Дата
Инвентарный номер техники
Вид работ (ТО, Ремонт, Диагностика и др.)
Описание
Исполнитель
Результат
Стоимость работ

Особенность: при добавлении записи с видом работ «ТО» автоматически обновляется поле «Дата последнего ТО» у соответствующей единицы техники.
5.5. Админ-панель (только для администраторов)

Пользователи системы — список всех учётных записей, добавление, изменение роли и пароля, удаление (учётную запись admin удалить нельзя).
Системная информация — количество записей техники, ответственных, обслуживания и пользователей.
Экспорт всех данных — скачивание JSON-файла с техникой, ответственными, журналом и пользователями.
Импорт данных — загрузка ранее экспортированного JSON-файла.
Сбросить к демо-данным — восстановление исходного набора техники, ответственных и записей обслуживания (пользователи не затрагиваются).

5.6. Инструкция
Краткое встроенное руководство пользователя (доступно всем).

6. Экспорт и импорт данных

Экспорт создаёт файл вида Uchet_tehniki_ГГГГ-ММ-ДД.json.
Файл содержит объект с полями data (техника, ответственные, обслуживание) и users.
При импорте система принимает как полный экспорт, так и файл, содержащий только данные техники.
Пароли пользователей при импорте сохраняются только если они не замаскированы.

Рекомендуется регулярно делать экспорт для резервного копирования.

7. Рекомендации по работе

Всегда используйте уникальные инвентарные номера.
Для списания техники меняйте статус на «Списано», а не удаляйте запись.
После проведения ТО обязательно добавляйте запись в журнал обслуживания — дата последнего ТО обновится автоматически.
Перед массовыми изменениями или экспериментами делайте экспорт данных.
Данные привязаны к браузеру и профилю пользователя. При очистке данных браузера или работе с другого компьютера информация будет потеряна (если не был сделан экспорт).
